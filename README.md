## 四、课程群叙事（三级台阶）

| 学期 | 课程 | 台阶 | 定位 |
| --- | --- | --- | --- |
| 第 3 学期 | 本课（数据接入 / 湖仓 / 特征语料 / 交付看板） | **筑基** | 把水抽干净，止于数据准备 |
| 第 4 学期 | 数据分析挖掘开发实践 | **赋能** | 在干净特征表上做分析 |
| 第 5–6 学期 | 多模态 / 综合应用实践 | **跃升** | 基于攒下的数据做 AI 应用、智能体 |

- 本课「不做模型训练、`si_label` 只是质量标签」的边界，在课程群叙事中的正当性：**不是不敢做 AI，是这一级只负责把井打深**。
- 申报材料论证角度：**「智能体是树，数据中台是土」「模型可以一年一换，基座要用十年」** —— AI 时代最先稀缺的是能搭可靠数据流水线的人。
- 第一次课体感锚点：「井里没水，抽上来的都是泥沙」，配合 29602 行带缺失、非法时间戳的原始传感器数据。

## 五、边界提醒（适用本库所有毕设题目）

1. **不写规划**：校级预算排序、数据交易所、跨部门确权不进课题内容（最多第一次课 10 分钟当背景）；学生写的是流水线与工具，规划是课程组的事。
2. **数据合规**：校园真实数据必须先过学校审批、脱敏、最小必要授权再进机房。
3. **不做真实工业控制**：仿真类题目均不接真实电网 / DCS / 窑炉，不声称工业控制效果、不做工业安全认证。
4. **不编造引文**：开题报告参考文献仅给检索方向，须按学校格式补实际文献。
5. **AI 边界**：筑基类题目不训练模型；AI 仅作辅助，不生成结论、不替代口径定义与核验。
